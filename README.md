# Bigger Worlds — GitHub Pages website prototype

Original static site adapted from the approved visual direction. No Nancy Eisenfeld artwork or other third-party creative artwork is included.

## Preview
Open index.html locally, or publish all site files and the assets folder to your GitHub Pages repository's root and enable GitHub Pages in Settings → Pages (deploy from branch).

## Before launch
1. Replace Episode 1 coming-soon content with the real YouTube embed and RSS/audio links when published.
2. Set `discourseUrl` in `script.js` to your live forum URL.
3. Connect the guest nomination form to an actual submission service (such as Formspree) or a backend before inviting real submissions. Currently it only prepares copyable text; **it sends nothing**.
4. Confirm final show title/name rights, branding, launch date, schedule, accessibility, privacy policy, and site domain.
5. Review all copy and imagery.

This is a development prototype, not a fully configured public launch site.
